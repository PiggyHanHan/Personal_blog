# 旅行者的见闻录 —— 原神风格个人博客

> 当前阶段：**纯文字骨架版** —— 只有内容和页面结构，还没有视觉设计。
> 下一步：在这个骨架上逐步加原神风格主题。

## 这是什么

一个基于 Next.js 的个人博客。目前是"纯文字版"，目的是先把**内容结构和文案**确定下来，确认无误后再一层层加上原神风格的设计（七元素配色、冒险家档案、元素轮盘、星空视差背景等）。

技术栈刻意保持最小：Next.js + React + TypeScript，没有任何样式框架和花哨依赖，方便之后逐步叠加。

## 怎么运行

需要 Node.js 18.18 及以上（当前环境是 Node 24）。

```bash
# 1. 安装依赖（第一次运行才需要）
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开
#    http://localhost:3000
```

生产构建（部署前检查用）：

```bash
npm run build
npm run start
```

## 目录结构

```
app/                  # 页面（Next.js App Router）
  layout.tsx          # 全站布局：顶部导航 + 页脚
  page.tsx            # 首页：自我介绍 + 冒险者档案 + 最近文章
  posts/
    page.tsx          # 文章列表页 /posts
    [slug]/page.tsx   # 文章详情页 /posts/xxx（按 slug 动态生成）
  about/page.tsx      # 关于页 /about
  globals.css         # 全局样式（目前是白底黑字的极简样式）
lib/
  posts.ts            # ★ 文章数据：加新文章就改这个文件
```

## 怎么加一篇文章

打开 `lib/posts.ts`，在 `posts` 数组里加一项：

```ts
{
  slug: "my-new-post",                 // 链接会是 /posts/my-new-post
  title: "文章标题",
  date: "2026-02-01",
  excerpt: "列表页显示的摘要一句话",
  tags: ["AI", "笔记"],
  content: ["第一段文字", "第二段文字"], // 每个字符串是一段
},
```

保存后刷新页面，新文章会自动出现在列表页和首页。
