## 一、外观调整（候选清单）

| # | 项目 | 说明 | 推荐 |
|---|---|---|---|
| A1 | **立绘 hover 互动** | 胡桃立绘悬停时轻微浮动 + 金色描边呼吸发光（CSS transition），不用鼠标时静止 | ⭐ 推荐 |
| A2 | **滚动淡入** | 各区块进入视口时轻微上浮淡入（IntersectionObserver），遵守 prefers-reduced-motion | ⭐ 推荐 |
| A3 | **导航选中态过渡** | 左侧导航当前项背景/竖线淡入淡出，hover 有微滑效果 | 推荐 |
| A4 | **卡片 hover 统一** | 文章/友链/项目卡 hover 统一为"上浮 3px + 阴影加深 + 金边亮起"（目前已有部分，统一力度） | 推荐 |
| A5 | **背景轮播过渡** | 背景图切换增加缓慢的交叉淡入（现在切换可能生硬） | 可选 |
| A6 | **标题金线生长** | 区块标题右侧金线 hover 时延伸（纯装饰，慎用） | 可选 |
| A7 | **移动端细节** | 窄屏卡片间距、立绘尺寸、时间轴缩进再校一遍 | 可选 |
| A8 | **页面切换过渡** | 路由切换时内容区轻微淡入（App Router transition，克制做） | 可选 |

## 二、互动小道具（候选清单）

> 素材已备：`public/hutao/待用库/胡桃音频/`（4 段语音）、火元素图样、chibi Q 版图。

| # | 道具 | 说明 | 推荐 |
|---|---|---|---|
| B1 | **胡桃语音彩蛋** | 点击立绘 / 火系神之眼，随机播放一句胡桃台词（用现有音频素材，带开关） | ⭐ 强烈推荐（素材现成） |
| B2 | **火元素点击粒子** | 点击页面任意处迸发几粒火元素粒子（CSS/轻量 Canvas，几毫秒消散，克制） | ⭐ 推荐 |
| B3 | **返回顶部按钮** | 滚动超过一屏出现，右下角"↑"（避免与设置按钮重叠，移到设置按钮左侧） | ⭐ 推荐 |
| B4 | **打字机标题** | 首页名字逐字打出（一次性，reduced-motion 关闭） | 可选 |
| B5 | **访客计数器** | 网站访问次数（localStorage 简单版，或后端计数；展示"第 N 位访客"） | 可选 |
| B6 | **小幽灵跟随** | 一只 Q 版胡桃/小幽灵在页面角落跟着鼠标轻轻移动（可开关，怕乱可不做） | 可选 |
| B7 | **音乐播放器** | 页面右下迷你播放器播放 BGM（素材缺，需用户提供音频） | 待素材 |
| B8 | **彩蛋文案** | 点击页脚年份/某个角落，冒出一句胡桃口吻的话 | 可选 |

## 三、实现顺序建议

1. **第一批（外观，低风险）**：A1 立绘 hover + A3 导航过渡 + A4 卡片统一 + A2 滚动淡入
2. **第二批（道具，用现成素材）**：B3 返回顶部 + B1 胡桃语音彩蛋 + B2 火元素点击粒子
3. **第三批（进阶，用户补充素材/想清楚再做）**：B5 访客计数、B6 小幽灵、B7 音乐、B4 打字机、A5-A8

> 原则：动效全部尊重 `prefers-reduced-motion`；小道具带开关（进设置面板或代码常量关闭）；不做与主题无关的装饰。
