# 从零启动博客并让朋友访问（保姆级）

> 写给完全不懂 IT 的博客主人。照着做就行，每步都有"看到什么算成功"。
> 本博客已移除一键脚本，全部手动操作，共 **2 个黑窗口**：博客服务窗口 + 公网隧道窗口。

---

## 第 1 步：启动博客服务

1. 按 `Win` 键，搜索 **PowerShell**，打开（不用管理员）
2. 输入下面这行，回车（这是进到博客文件夹）：
   ```
   cd E:\Projects\Personal_blog
   ```
3. **只有改过代码/换过素材后**才需要先重新构建（平时跳过）：
   ```
   node node_modules\next\dist\bin\next build
   ```
   看到一大串输出、最后有 `Generating static pages` 之类就算完成。
   > 注：这里用 `node` 直接跑 next，绕开了 `npm`——本机的 `npm` 命令被 `C:\Windows\System32\npm`（一个 0 字节空文件）劫持了，暂时用不了；以后修好 npm 后可改回 `npm run build`。
4. 启动服务（**80 端口**）：
   ```
   node node_modules\next\dist\bin\next start -p 80
   ```
   **看到 Ready / started server 字样 = 成功。这个窗口全程别关。**

> 验证（可跳过）：浏览器打开 `http://localhost` 能看到开屏动画就说明服务起来了。

---

## 第 2 步：启动隧道（给朋友公网地址）

1. **再开一个** PowerShell 窗口（同样不用管理员）
2. 粘贴这行，回车：
   ```
   & "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:80 --no-autoupdate
   ```
3. 等 5~10 秒，输出里会出现一个框：

   ```
   Your quick Tunnel has been created! Visit it at:
   https://xxxx-xxxx-xxx.trycloudflare.com
   ```

   **框里那个 `https://...trycloudflare.com` 就是给朋友的地址**，复制下来。

   **这个窗口也全程别关。**

---

## 第 3 步：验证并发给朋友

1. 你自己先浏览器打开那个 `https://...trycloudflare.com` 地址
   - 能看到开屏动画（往生堂的门，点进去）→ 成功 ✅
   - 打不开 → 看下面的"常见问题"
2. 把地址发给朋友，他任何网络（Wi-Fi / 手机流量）都能打开

---

## 停止

- 两个窗口都关掉（或分别按 `Ctrl+C`），服务就停了
- 电脑关机/睡眠，朋友也访问不了

---

## 常见问题

**打不开 / 白屏 / 连接失败**
- 两个黑窗口是不是都还开着？（哪个关了补哪个）
- 浏览器地址是不是完整复制的（`https://` 开头、`.trycloudflare.com` 结尾）

**提示端口被占用（80 端口被占）**
- 先停掉别的占用程序，或在 PowerShell 里看：`netstat -ano | findstr ":80 "`

**改完代码页面没变化**
- 你只重启了服务但没重新构建：回到服务窗口按 `Ctrl+C` 停掉，重新执行第 1 步的 **build** 命令再启动

**地址变了**
- 每次重新启动隧道都会换一个新地址，属正常；拿新地址重新发朋友即可

**朋友打不开但我能打开**
- 让他换手机流量试试；还不行让他把报错截图发你
