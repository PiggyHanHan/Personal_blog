## 场景四：全新部署

```powershell
cd E:\Projects\Personal_blog
.\deploy-full.ps1
scp -i "C:\Users\28646\.ssh\PiggyHanHan.pem" blog-full.tar.gz root@114.55.74.46:/var/www/
```
登录服务器：
```bash
cd /var/www
mv blog blog_backup_$(date +%Y%m%d) 2>/dev/null
tar -xzf blog-full.tar.gz
rm blog-full.tar.gz

if [ ! -d "blog" ]; then
    mkdir -p blog
    for item in *; do
        if [ "$item" != "blog" ]; then
            mv "$item" blog/
        fi
    done
fi

cd blog
npm install
npm run build
pm2 start npm --name blog -- start -- -p 3000
pm2 save
pm2 startup
```

Nginx 配置（一次性）：
```bash
cat > /etc/nginx/sites-available/blog << 'EOF'
server {
    listen 80;
    server_name _;

    # 1. Next.js 的 JS/CSS 构建产物
    location /_next/static/ {
        alias /var/www/blog/.next/static/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 2. PDF 附件（直接从 content/files/ 读取，不经过 Node）
    location /files/ {
        alias /var/www/blog/content/files/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 3. 其他静态资源（背景图、开屏素材、压缩配图等）
    #    先到 public/ 找，找不到再转发给 Node
    location / {
        root /var/www/blog/public;
        try_files $uri @nextjs;
    }

    # 4. 转发给 Next.js 服务
    location @nextjs {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
EOF
ln -sf /etc/nginx/sites-available/blog /etc/nginx/sites-enabled/blog
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```
浏览器访问 `http://114.55.74.46` 验证。
