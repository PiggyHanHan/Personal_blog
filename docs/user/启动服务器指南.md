# 博客部署指南

> 两种方式：本地开发 + 云服务器上线。

---

## 一、本地开发（电脑上跑）

### 启动

```powershell
cd E:\Projects\Personal_blog
npm run build
npm run start -- -p 80
```

浏览器打开 `http://localhost` 能看到博客 = 成功。

### 改完代码后

```powershell
# Ctrl+C 停掉服务，然后重新构建启动
npm run build
npm run start -- -p 80
```

### 2.1 首次部署（只做一次）

#### 第一步：打包上传

```powershell
cd E:\Projects\Personal_blog

# 打包项目
.\deploy-pack.ps1

# 上传打包文件
scp -i "C:\Users\28646\.ssh\PiggyHanHan.pem" blog.tar.gz root@114.215.204.241:/var/www/blog.tar.gz

# 上传背景图和开屏素材（这两个目录较大，单独传）
scp -r -i "C:\Users\28646\.ssh\PiggyHanHan.pem" public\bg root@114.215.204.241:/var/www/blog/public/
scp -r -i "C:\Users\28646\.ssh\PiggyHanHan.pem" public\hutao root@114.215.204.241:/var/www/blog/public/
```

#### 第二步：服务器上构建启动

```powershell
# 登录服务器
ssh -i "C:\Users\28646\.ssh\PiggyHanHan.pem" root@114.215.204.241

# 在服务器上执行
cd /var/www/blog
tar -xzf blog.tar.gz
rm blog.tar.gz
npm install
npm run build
pm2 start npm --name blog -- start -- -p 3000
pm2 save
exit
```

看到 `Ready` 字样 = 成功。

#### 第三步：开放安全组端口（只做一次）

1. 登录 https://ecs.console.aliyun.com
2. 点实例 ID → 左侧"安全组" → 点安全组名称
3. "入方向" → "手动添加"：
   - 协议：自定义 TCP
   - 端口：80/80
   - 来源：0.0.0.0/0
   - 描述：HTTP
4. 保存

浏览器打开 `http://114.215.204.241` 验证。

```powershell

# 2. 上传
```

### 2.3 常用命令

| 操作 | 命令 |
|---|---|
| 查看状态 | `ssh ... "pm2 status"` |
