# 怎么访问我的博客

我的博客跑在自己电脑上，通过 Cloudflare 隧道提供**公网访问**，不需要任何 App、不需要部署到服务器，任何网络（Wi-Fi / 手机流量 / 公司网）都能打开。

## 一、直接打开这个地址

在浏览器**原样粘贴**：

```
https://pride-securities-recognized-prophet.trycloudflare.com
```

打开后如果看到开屏动画（往生堂的门，点击进入），就成功了。

## 二、打不开怎么办

1. **换网络重试**：Wi-Fi 不行换手机流量试试（一般都能打开）
2. 确认地址没打错、没多空格
3. 还不行就告诉我（博客主人），我检查电脑这边

## 三、注意

- 我的电脑开机、服务在跑的时候才能访问；电脑关机就打不开
- **这个地址是临时的**：我这边重启服务/隧道后地址会变，打不开了就来问我要最新地址
- 以后我会部署到正式服务器，到时候就是固定网址，随时能访问
