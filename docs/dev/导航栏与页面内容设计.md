# 导航栏与页面内容设计

> 状态：**已定稿**（2026-08-10）
> 依据：参考朋友的博客 LemonNK（极简单列 + 归档/项目）、HuajiMC（大名字 Hero + 分类 + 友链），并融合用户要求（首页放个人信息 + 技术栈 + 胡桃证件照）。

---

## 一、导航栏项（已确认：5 项，不建分类）

| 项 | 路由 | 内容 | 状态 |
|---|---|---|---|
| 首页 | `/` | 个人主页：Hero + 技术栈 + 最新文章 | 重构中 |
| 文章 | `/posts` | 全部文章卡片列表（标签徽章区分） | 已有 |
| 友链 | `/links` | 朋友的链接（仿 HuajiMC My Friends） | 新建 |
| 项目 | `/projects` | 作品/项目展示（仿 LemonNK Projects） | 新建 |
| 关于 | `/about` | 个人图鉴：档案、自我介绍、技能、写作方向、联系 | 已有 |

> 不建内容分类（HuajiMC 的 Web/碎碎念），文章用标签区分；归档页不设（等文章多了再加）。

## 二、首页布局（已确认：三块，分块清晰）

```
┌──────────────────────────────┐
│ Hero 卡：                    │
│  ⬡ 胡桃证件照（头像框，用户提供）│
│  名字（大标题）               │
│  一句话身份                   │
│  签名                         │
│  [B站] [GitHub] [邮箱] 社交链接 │
├──────────────────────────────┤
│ 技术栈（标签组）              │
│  [AI/LLM] [Python] [TypeScript] │
├──────────────────────────────┤
│ 最新文章（标题/日期/标签）      │
│  … + 「查看全部 →」            │
└──────────────────────────────┘
```

- Hero 卡：左证件照右文字（桌面），窄屏上下排
- 技术栈：金色点缀标签组，可配置（lib/site.ts）
- 档案摘要从首页移除（关于页已有档案卡）

## 三、其他页面

- **文章页**：不变（页头 + 委托卡片列表）
- **友链页**：页头 + 友链卡片网格（名称 + 简介 + 链接）
- **项目页**：页头 + 项目卡片列表（名称 + 描述 + 链接）
- **关于页**：不变（档案卡 + 自我介绍 + 技能 + 写作方向 + 联系）
- **文章详情**：不变（返回 + 元信息 + 块级正文 + 上一篇/下一篇）

## 四、配置

- 全部文案 / 数据收敛在 `lib/site.ts`：导航、Hero（名字/身份/签名/证件照路径/社交链接）、技术栈、友链、项目
- 胡桃证件照：用户提供图片放入 `public/`，改 `lib/site.ts` 的 `avatar` 路径即可（实现时先用现有 Q 版胸像占位）
