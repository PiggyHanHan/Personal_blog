# 博客内部定制化 · 整体结构设计

> 状态：**已实现**（2026-08-10 完成，构建与页面验证通过）
> 范围：重构博客"内部层"——首页 / 文章列表 / 文章详情 / 关于页 / 导航页脚，以及正文数据模型。
> 不动：开屏动画、背景轮播机制、设置按钮、音效系统。

---

## 一、设计基调

| 项 | 决定 |
|---|---|
| 视觉 | **浅色为主**：米白 / 羊皮纸色底 + 深暖棕文字（替代现在的"深色遮罩 + 文字背光"） |
| 点缀 | **原神元素点缀**：金色渐变边框角饰（复用 `public/border/genshin-frame-*.svg` 的菱形角饰/回纹语言）、火系神之眼、标签徽章、金线分隔 |
| 布局 | 首页/列表/详情：**单列纵向、内容靠左**（限制行宽，左对齐；不搞双栏） |
| 语气 | 延续胡桃 · 璃月调性（见闻录 / 委托 / 档案） |

## 二、信息架构（保持三页，不新增）

```
/                首页    = 冒险者档案馆（档案卡 + 委托板）
/posts           列表    = 全部委托（卡片列表，按日期倒序）
/posts/[slug]    详情    = 委托详情（结构化正文 + 上一篇/下一篇）
```

> 页面范围随"单列纵向"布局走：单列流下不需要独立归档页/标签页，先做精三页。
> 预留：若未来文章量变大，再加 `/archive` 或标签筛选（组件层面已留 TagPill 可复用）。

内容容器：`max-width: 860px`，`margin-left: auto; margin-right: auto`（容器居中）但内部文字一律**左对齐**，不做居中标题排版。区块自上而下：

| 序 | 区块 | 内容 | 标题候选（待定） |
|---|---|---|---|
| 1 | 扉页引言 | 站点名 + 一句话欢迎（胡桃味） | 「见闻录」扉页 / 直接不设标题只放引言 |

## 七、正文数据模型（推倒重来）

现状 `content: string[]`（纯段落）无法支撑定制化排版。升级为**块级结构**：

```ts
export type Block =
  | { type: "heading"; level: 2 | 3; text: string }   // 小节标题
  | { type: "paragraph"; text: string }               // 段落
  | { type: "quote"; text: string }                   // 引用（金色左边线）
  | { type: "list"; ordered?: boolean; items: string[] } // 列表
  | { type: "code"; lang?: string; code: string }     // 代码块（深底圆角）
  | { type: "image"; src: string; alt?: string; caption?: string } // 插图
```

- `Post.content` 改为 `Block[]`；数据源为 `content/posts/*.md`（frontmatter + Markdown），由 `lib/markdown.tsx` 解析回 `Block[]` 供 `PostBody` 渲染
- 渲染组件 `components/post/PostBody.tsx`：逐块渲染，每块有定制样式
- 示例文章 `hello-world` 迁移到 `content/posts/hello-world.md` 作为示范

## 九、视觉规范

### 色板（浅色基调）
| 用途 | 色值 |
|---|---|
| 页面氛围底 | 米白 `#f7f1e3`（背景图提亮后的浅色氛围） |
| 卡片底 | 羊皮纸 `#fdfaf2`，透明度 0.9 |
| 主文字 | 暖深棕 `#3a2e26` |
| 次要文字 | `#8a7a6a` |
| 主色（深红·胡桃） | `#8c2f39`（标题、链接、徽章字） |
| 点缀色（璃月金） | 渐变 `#f8e7b0 → #dfc06e → #bd9a44`（描边、角饰、分隔线） |

### 卡片样式
- 羊皮纸底 + 1px 金色渐变描边 + 8px 圆角 + 柔和投影
- 四角金色菱形角饰（用 CSS `::before/::after` + 线性渐变自绘，或复用 border SVG 局部；**先用 CSS 角饰实现，轻量且不依赖大图**）
- hover：描边加深 + 轻微上浮

### 标题体系
- 区块标题：左对齐，左侧 3px 深红竖条 + 右侧金色渐变横线延伸
- 正文标题：h2 深红、h3 暖棕加粗

### 导航 / 页脚
- 顶栏：米白半透明（毛玻璃 blur），链接为金色描边胶囊，当前页实底金
- 页脚：金线分隔，暖棕小字

### 背景处理（已确认：全屏背景图保留）
- **保留全屏风景轮播不动**（轮播机制、遮罩强度均保持）。
- "浅色为主"仅指**内容层**：卡片、正文用米白/羊皮纸浅色底 + 深暖棕文字，替代现在的"深色遮罩 + 白色文字背光"。
- 浅色卡片浮在背景图之上，页面空白处仍透出背景风景图 —— 背景保留特色、内容层浅色可读，互不冲突。

## 十、已确认决策

1. **背景**：全屏轮播保留；内容层浅色卡片化。
2. **标题**：用户自定义。全部文案收敛到 `lib/site.ts` 常量（占位文案实现，改名只动一处）。
3. **正文**：采用第七节块级结构。
4. **扉页引言**：保留，不设标题。
5. **首页布局**：单列纵向、内容靠左。
