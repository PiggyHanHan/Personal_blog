## 做了什么

把原来糊糊的原神视频开屏换成了**胡桃·往生堂风格**的开门动画。

### 新开屏流程

1. 进站先看到往生堂的门，点击后门淡出、白屏淡入
2. Q版胡桃蹦出来 + 底部加载进度条
3. 进度条左右各一颗璃月火系神之眼（加载中宝石中间闪烁，加载完定格最亮）
4. 火元素图样绕着神之眼摆动式外溢
5. 进度加载完，第一张胡桃换成第二张，停留约 2.8s 再进站
6. 白屏的装饰背景 = 博客背景当前图虚化，过渡连贯不跳

### 素材折腾

- 胡桃两张 Q 版图是白底的，火元素图样、神之眼也都是白底
- 写了个脚本用 floodfill 抠白底转透明 PNG + 边缘羽化
- 素材统一放 `public/hutao/`，分成 `背景/`、`小素材/`、`待用库/` 三个子目录

### 技术备注

- 背景轮播抽成 `BgProvider`（Context），开屏白屏和博客背景共用同一轮播源，保证同步
- 素材预加载用 `naturalWidth` 判断是否缺失，缺图自动降级，不会卡死、不显示破图
- 修了 SSR 时 `<img>` 的 `onLoad`/`onError` 事件丢失的问题（hydration 前图片就加载完/失败）

## 追加：音效 + 胡桃互动 + 收窗帘进站（同日续写）

开屏定稿后又做了三块：声音、第一屏胡桃、进站过渡。

### 声音系统（全手动素材，缺文件静默降级）

- 3 个音效点位 + 1 个欢迎语，`wav`/`mp3` 兼容（同名优先 wav）：
  - 点击开门：`音效/door-open` + 欢迎语 `录音/你很有眼光嘛！.wav` **同时播**
  - 进度满、胡桃切第二张：`音效/起！.wav`（胡桃战技）+ `音效/energy-full.wav`（神之眼充能，同步）同步播放
- 第一屏点胡桃：随机播一条胡桃台词（不连续重复）；再点打断重随机；**点开门时正在播的台词 1s 渐弱结束**
- 门音从录屏提取：先频谱减法去背景，发现太闷/卡（削了瞬态），退回"裁剪 + 高通 100Hz"直出
- 充能音从录屏提取：频谱分析定位到 6.0s 才响（不是以为的 5s），裁 6.0s 起 + 高通 150Hz

### 录音随机池（关键设计）

用户录音是**任意中文文件名**，没法像 `voice-1.mp3` 那样连续探测：
- 加了个 API 路由 `app/api/voices/route.ts`，用 `fs` 枚举录音目录，返回文件名列表
- 客户端拉一次列表，动态建 `Audio` 池 → **往目录丢任意 wav/mp3 自动进随机池，不用改代码**

### 素材目录重构

`public/hutao/` 改成两大类：

- `使用中/`（背景 / 小素材 / 音效 / 录音）
- `待用库/`（未用素材，与使用中彻底隔离）
