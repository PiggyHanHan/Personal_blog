### 做了什么

- **新建 `content/posts/hello-world.md`**：原硬编码文章迁为 frontmatter（title/date/excerpt/tags）+ Markdown 正文。
- **新建 `lib/markdown.tsx`**：`unified + remark-parse` 把正文解析成 mdast 树 → 映射回 `lib/posts.ts` 的 `Block[]`（heading/paragraph/quote/list/code/image）；行内格式（**粗体**、*斜体*、`行内代码`、链接、删除线）转成 React 元素。
- **重写 `lib/posts.ts`**：从 TS 数组改为 `fs` 读取 `content/posts/*.md`，frontmatter 用 gray-matter 解析；slug 校验（仅英文/数字/下划线/连字符，中文 slug 详情页 404 并给出明确报错）。
- **补 `.post-body` 行内样式**：行内代码（`:not(pre) > code` 避免误伤代码块）、链接（绯红 + 下划线）、粗体、删除线。
- **文档同步**：README「怎么加一篇文章」改为 Markdown 写法 + 目录结构（嵌套代码块用**四反引号**围栏，三反引号会提前终止）；`docs/整体结构设计.md` 更新 Block 数据源说明。
- **构建坑**：`npm.cmd run build` 不可靠，按 `docs/启动服务器指南.md` 用 `node node_modules\next\dist\bin\next build`。

### 修的 bug

- **列表页日期显示 `1970-01-01`**：YAML 裸日期 `2026-08-10` 被 js-yaml 解析成 **Date 对象**而非字符串，`str()` 只认字符串落入 fallback。修复：`str()` 兼容 `Date` 实例。

### 手机 PDF 方案（pdf.js）

- 现象：小米等国产浏览器不支持 iframe 内嵌 PDF（iframe 一律弹下载）。
- 方案落地：
  - **桌面**：原生 `<iframe src="/api/view/...">`（`Content-Disposition: inline`，浏览器内置阅读器）。
  - **手机**：`components/post/MobilePdfViewer.tsx` 用 pdfjs-dist **legacy build**（兼容老内核）canvas 渲染，滚动懒加载（先 3 页，滚到底继续），45s 下载超时保护；worker 用 `new URL(..., import.meta.url)` 输出为静态资源。
  - **手机端绝不能渲染 iframe**（即使 CSS 隐藏也会加载 PDF 触发下载弹窗）；移动端判断用 **UA + `(pointer: coarse)` + maxTouchPoints**，不用视口宽度（iPad/折叠屏/电脑模式会误判）。
- 详情页 PDF 预览区加「新窗口打开」「下载 PDF」按钮（`/api/download`）。
- 同步更新 `docs/内容更新指南.md`（放 PDF/附件一节）。

### 返回列表定位

- 详情页「← 返回文章列表」改为 `/posts?post=<slug>`。
- `TabbedSections` 新增 `initialTabName`（初始选中 tab）+ `scrollToSlug`（渲染后滚动到卡片居中）；`QuestCard` 加 `data-slug` 锚点。
- Playwright 实测：从《个人焦虑的剖析与总结》返回 → URL `/posts?post=anxiety-analysis`、自动选中「个人文章」tab、目标卡片滚动到视口正中（卡片中心 209.5 vs 视口中心 210）。

### 背景连续性修复（背景随导航重载）

- 用户反馈：首页/文章/详情页之间切换时**背景会变**，网卡时**先黑后显示**——说明背景图被重新加载。
- 根因：layout 每次客户端导航都会重新执行，`getBgImages()` 返回**新数组引用**，`BgProvider` 的洗牌 `useEffect` 依赖该数组，一变就重新洗牌 → 换新图 → 新 URL 重新下载 → 黑屏。
- 修复：洗牌结果 `order` + 当前索引 `idx` **持久化到 sessionStorage**（`blog-bg-state`，恢复时校验图片数一致），导航或刷新后恢复同一张图，URL 不变 → 浏览器缓存命中 → 无缝显示。
- Playwright 实测：首页→文章→详情（SPA）背景全程同一张 `/bg/downloaded-image (2).jpeg`，整页刷新后仍是同一张。

### 导航性能修复（文章页切换卡顿 + 开屏重播）

- 用户反馈：切其他页面快、切文章有延迟，第一次切文章还重播完整开屏。
- 根因 1：`app/posts/page.tsx` 服务端读 `searchParams` → `/posts` 变**动态渲染（ƒ）**，其余页面静态（○）；隧道访问下切换慢，请求失败降级整页刷新。
- 根因 2：IntroOverlay 无"已看过"持久化，任何整页加载重播开屏。
- 修复：
  - `/posts` 静态化（ƒ→○）：`?post=` 定位移到客户端，`TabbedSections` 用 `useSearchParams` + 静态 `slugToTabName` 映射；`posts`/`projects` 页补 `<Suspense>` 边界（useSearchParams 静态渲染要求）。
  - IntroOverlay 会话去重：sessionStorage `blog-intro-seen=1`，同标签页整页加载不再重播开屏，新开标签页/新会话正常重播。
- 验证：build 通过（/posts 变 ○）；Playwright 切换耗时 118ms→47ms；整页刷新不重播、新标签页重播；`?post=` 返回定位 tab 正确。

## 全天教训小结

- 本机 `npm` 被空文件劫持：装依赖/构建一律 `npm.cmd`（或 `node node_modules\next\dist\bin\next build`）。
- YAML 裸日期会被解析成 Date 对象，取日期字段要兼容 Date。
- 导航类 bug 先确认是不是整页加载：`performance.getEntriesByType('navigation')` 的 `timeOrigin` 变化即整页导航。
- 处理混合编码文件前先做字节级诊断，别用 `errors="replace"` 读回写（会把无法解码的字节永久替换成 U+FFFD）。
- 手机端 PDF 只能走 pdf.js canvas，绝不能渲染 iframe（会触发下载弹窗）。
