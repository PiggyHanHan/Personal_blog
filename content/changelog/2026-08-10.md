- **建站**：博客「旅行者的见闻录」上线，全站以胡桃主题深度定制。
- **开屏动画**：胡桃·往生堂风格的「开门」动画，含加载进度条与音效；点开屏里的胡桃会随机说一句台词。
- **音量设置**：右下角齿轮按钮可调节开屏音效与胡桃语音的音量，记忆你的偏好。
- **左侧垂直导航栏**：首页 / 文章 / 友链 / 项目 / 关于 五大板块，随页面滚动常驻。
- **首页个人主页**：名片（姓名 / 学校 / 学院 / 班级 / 科研方向 / 座右铭 / 社交链接）、技术栈进度条、经历时间线、精选项目、个性化（游戏 / 歌手 / 装备工具）。
- **新增页面**：项目页（学术 / 个人两列 + 重要性标识）、友链页（一人一行卡片）、关于页。
